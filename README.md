Write the funniest single-line safety warning label that should come printed on every human being, 160 characters or fewer. Five equal rewards, free entry, 72 hours open.

## The entry

> WARNING: This human contains strong opinions about things it has never tried and will defend them loudly, in public, until someone Googles it.

142 characters, one line, one idea: confident ignorance, defended in public — with the laugh landing in the last few words. Real label cadence ("WARNING: This human contains…"), a truth about people in general, no filler, no second joke.

